# LinkedIn Content Engine

A reusable Manus Skill for drafting, editing, evaluating, and cautiously learning from individual LinkedIn posts.

## What it does

- Creates and revises posts from a brief, audience, evidence, objective, and approved author voice.
- Separates user-provided facts from claims that need verification.
- Uses supplied performance data to identify observations, hypotheses, and one next test.
- Keeps author context and client information outside the neutral reusable package.

## What it does not do

- Optimize LinkedIn profiles or produce full editorial calendars.
- Copy another creator's distinctive wording or invent personal experience, metrics, sources, or outcomes.
- Promise virality, reach, leads, or detector evasion.
- Publish, schedule, comment, or message automatically.
- Learn or update persistent instructions without user approval.

## Use

Install or attach the Manus Skill, then provide a post brief or draft. For author-specific voice and context, supply authorized examples or use an appropriate private Project/voice Skill. Do not place private client data in this public package.

## Requirements

No custom scripts, API credentials, paid services, or external integrations are required by the Skill. Research or analytics integrations are not included.

## Validation and limitations

The v0.1.0 candidate passes the official Skill structural validator. Behavioral cases were reviewed against the instructions but not independently executed; automatic activation and actual LinkedIn analytics/publication were not tested. See `docs/TESTS.md`.
